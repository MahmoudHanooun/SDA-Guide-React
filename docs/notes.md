# Technical Note

## Biggest Docker problem I faced and how I solved it
The biggest problem I faced was that my Docker container showed an unhealthy status, even though the website was working. I checked the Docker logs and health status and found that the health check was failing. I fixed the HEALTHCHECK command in the Dockerfile, rebuilt the image, and restarted the container. After that, the container showed a healthy status.


## Most important Git/GitHub lesson
The most important lesson I learned was how to use Git to track changes in my project and GitHub to store and share my code. I also learned that after making changes, I need to add, commit, and push them to GitHub so the online repository stays updated.
